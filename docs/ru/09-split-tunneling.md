# Раздельное туннелирование: банки напрямую, YouTube через VPN

Если пускать через VPN весь трафик, начинаются проблемы: банковские приложения и Госуслуги не открываются с зарубежных IP, маркетплейсы показывают другую валюту, скорость российских сайтов падает. Решение — **раздельное туннелирование** (split tunneling): через VPN идут только заблокированные сервисы, всё остальное — напрямую.

## Два подхода

| Подход | Как работает | Кому подходит |
|---|---|---|
| **«Россия напрямую»** | всё через VPN, кроме российских сайтов и IP | большинству: ничего не нужно поддерживать, новые заблокированные сервисы откроются сами |
| **«Только заблокированное через VPN»** | напрямую всё, кроме списка заблокированных сервисов | если VPN медленный или с лимитом трафика; список придётся обновлять |

## Готовые списки

В папке [`lists/`](../../lists) этого репозитория:

- [`blocked-services.txt`](../../lists/blocked-services.txt) — домены заблокированных сервисов (YouTube, Instagram, Discord, WhatsApp и др.);
- [`ru-direct.txt`](../../lists/ru-direct.txt) — что пускать напрямую: зоны .ru, .su, .рф и российские сервисы на других доменах;
- [`xray-routing-example.json`](../../lists/xray-routing-example.json) — пример правил для клиентов на ядре Xray, сочетающий оба списка.

## Настройка в клиентах

**Hiddify.** В настройках выберите регион **«Россия»** (Region / Country) — клиент сам пустит российские сайты напрямую. Это подход «Россия напрямую».

**v2rayNG.** Настройки → **Настройки маршрутизации** → добавьте правила: домены из `ru-direct.txt` и `geoip:ru` — в «Прямое подключение», при подходе «только заблокированное» — домены из `blocked-services.txt` в «Прокси», а правило по умолчанию — «Прямое».

**Happ и V2RayTun.** В разделе маршрутизации включите готовый набор правил для России, если он есть в вашей версии, или добавьте домены из списков вручную.

**Streisand.** В настройках подключения есть правила маршрутизации по доменам и IP — добавьте `ru-direct.txt` в прямое подключение.

> Названия пунктов меню отличаются от версии к версии. Если не нашли — ищите слова «Маршрутизация», «Routing», «Правила» или «Rules».

## Частые ошибки

- **Банк всё равно не открывается.** Некоторые банки используют домены вне зоны .ru — добавьте домен приложения в прямое подключение (посмотреть его можно в логах клиента).
- **Приложение Telegram не работает через «только заблокированное».** Приложения Telegram подключаются по IP-адресам, а не по доменам. Для него используйте MTProto-прокси ([раздел про Telegram](07-telegram.md)) или подход «Россия напрямую».
- **Не путайте с «раздельным туннелированием по приложениям».** В Android-клиентах можно выбрать, какие **приложения** идут через VPN — это другой, тоже рабочий способ.
