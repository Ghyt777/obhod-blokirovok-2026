# Подключение за 5 минут

1. Получите у VPN-сервиса ключ или ссылку-подписку и скопируйте её.
2. Установите клиент для своей платформы ([таблица клиентов](04-clients.md)).
3. В клиенте нажмите **«+»** → **«Импорт из буфера обмена»** (или отсканируйте QR-код).
4. Выберите сервер и нажмите кнопку подключения, разрешите создание VPN-подключения.
5. Включите **маршрутизацию для России** (в Hiddify — регион «Россия», в v2rayNG и Happ — правила маршрутизации), чтобы банки и Госуслуги открывались напрямую, без отключения VPN.

Не подключается? По порядку:
- попробуйте **другие серверы** из подписки — у разных операторов работают разные маршруты;
- обновите подписку;
- на мобильном интернете проверьте Wi-Fi — если там работает, скорее всего, действуют белые списки;
- попробуйте другой протокол, если сервис их выдаёт (Reality → XHTTP → Hysteria2).
