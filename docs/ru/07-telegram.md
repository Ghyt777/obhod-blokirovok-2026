# Telegram

Для одного Telegram VPN не обязателен — хватит **MTProto-прокси**: он встраивается прямо в приложение (Настройки → Продвинутые → Тип соединения → Использовать собственный прокси).

Если кнопка «Подключить прокси» в браузере ничего не делает, значит Telegram не зарегистрирован как обработчик ссылок `tg://` (так бывает с portable-версией и версией из Microsoft Store) — добавьте прокси вручную: сервер, порт и секрет.

Списки бесплатных и платных прокси: [прокси для Telegram](https://www.vpnmarket.online/telegram-proxy).
