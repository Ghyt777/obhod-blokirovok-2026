# Обход блокировок в России в 2026 году: что работает

Практический гайд: какие сервисы заблокированы, какие протоколы ещё проходят через ТСПУ, какие клиенты ставить и как подключиться за 5 минут. Плюс готовые списки доменов для раздельного туннелирования. Без воды и без «топ-10 лучших VPN» из рекламы.

> **Обновлено:** октябрь 2026. Ситуация меняется каждые несколько недель — если что-то устарело, откройте issue.
>
> 🇬🇧 [English version](docs/en/README.md)

## Коротко

- **Заблокированы:** YouTube, WhatsApp, Discord, Viber, Signal, Instagram, Facebook, X, LinkedIn; Telegram — с ограничениями.
- **Работают протоколы:** VLESS + Reality, VLESS + XHTTP, AmneziaWG, Hysteria2. Обычные WireGuard и OpenVPN массово блокируются.
- **Клиенты:** Happ, Streisand (iPhone/Mac), v2rayNG, NekoBox (Android), Hiddify (все платформы).
- **Банки и Госуслуги** открывайте напрямую через раздельное туннелирование — [готовые списки](lists/).

> 💬 **Что работает у вашего провайдера?** Делитесь короткими отчётами в [обсуждении по регионам](https://github.com/Ghyt777/obhod-blokirovok-2026/discussions/1) — по ним обновляется гайд.

## Об авторе и ссылках

Гайд ведёт автор каталога [vpnmarket.online](https://www.vpnmarket.online) — там данные о провайдерах (цены, протоколы, пробные периоды) сверяются с их официальными сайтами. Часть ссылок на VPN-сервисы в каталоге — партнёрские. Сам гайд — информационный материал, он не призывает нарушать закон.
